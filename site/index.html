前方高能！！！ 终于能在电视上刷弹幕了 4K HDR 太清楚了 2333333 手机点投屏就过来了 好方便 awsl 弹幕从人身后穿过去了？！

该有的都有，而且是原生的

不是网页套壳：播放用 tvOS 原生的 AVPlayer，界面为 Siri Remote 的焦点操作设计。

原生 4K / HDR 播放

4K / 8K、HEVC / AV1、HDR10 / HLG、杜比视界、杜比全景声与 FLAC；自动匹配动态范围与帧率，按带宽切换清晰度。

流畅弹幕 · 智能防挡

后台光栅化渲染，高密度弹幕也不卡；字号、速度、区域、密度、屏蔽词可调，同步账号屏蔽词；用 B站的人像蒙版让弹幕从人物身后穿过。

手机一键投屏

在官方 B站手机 App 里点「投屏」、选 Danmu TV：电视用自己的播放器打开同一个视频，弹幕、历史、清晰度都在；暂停、进度、倍速跟着手机走。

高能进度条

弹幕热度曲线画在进度条上方，最热闹的高能时刻会标在进度条上，可以直接跳过去。

互动视频 · 画中画

互动视频的剧情分支用遥控器选，支持返回上一步；画中画把视频缩到角落，一边看一边逛。

番剧 · 直播 · 评论区

番剧与影视（时间表、追番、跳过片头片尾），直播弹幕与醒目留言，评论区的楼中楼、图片和表情。

为遥控器设计

长按确认键临时 2× / 3× 倍速，连续播放和相关推荐自动播放，Top Shelf 显示继续观看。

多账户 · 不收集数据

扫码登录，最多 5 个账户，通过 iCloud 钥匙串在多台 Apple TV 间同步；没有任何统计或崩溃上报。

怎么安装

Danmu TV 不在 App Store 上架，也不提供安装包：用你自己的 Mac 和 Apple ID 从源码编译，装到自己的 Apple TV 上。

  1. 准备

    一台装了 Xcode 26 或更新版本的 Mac，brew install xcodegen，以及和 Mac 在同一网络的 Apple TV（tvOS 17+）。

  2. 下载源码并填写签名

    复制 Config/Local.xcconfig.example 为 Local.xcconfig，填入你的 Team ID 和一个属于你的 Bundle ID。

  3. 配对 Apple TV

    在 Apple TV 的「设置 › 遥控器与设备 › 遥控器 App 与设备」里，和 Xcode 的 Devices 窗口配对。

  4. 运行

    选择 DanmuTV scheme 和你的 Apple TV，按 ⌘R。免费 Apple ID 签名 7 天后需要重新安装，付费开发者账号一年有效。

git clone https://github.com/CurryFishBalls9527/DanmuTV.git
cd DanmuTV
cp Config/Local.xcconfig.example Config/Local.xcconfig
xcodegen generate
open DanmuTV.xcodeproj

常见问题

Danmu TV 是 B站官方的吗？

不是。Danmu TV 是独立的开源项目，与哔哩哔哩（上海宽娱数码科技有限公司）没有任何关联，也未获其授权或认可。

要钱吗？能在 App Store 下载吗？

完全免费，GPL-3.0 开源。它从未在 App Store、TestFlight 或任何平台上架，也不提供安装包；任何收费提供本项目的行为都与作者无关。

可以直接装别人打包好的版本吗？

不建议。Danmu TV 需要登录你的 B站账号，他人打包的版本可能被篡改，有盗号风险。请只从本仓库源码自己编译。

能看大会员内容吗？

需要你自己的大会员账号。Danmu TV 不绕过任何付费、会员、地区或版权限制，也不破解 DRM。

支持哪些 Apple TV？

tvOS 17 及以上的 Apple TV HD 和 Apple TV 4K。4K、HDR 和杜比视界需要 Apple TV 4K 和支持的电视。

界面有英文吗？

目前只有简体中文界面。
